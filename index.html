Connect

Only testnet runs. There is no dev environment.

  • REST: https://<testnet-api-hostname>:8443/v1/...
  • WebSocket: wss://<testnet-api-hostname>:8443/v1/ws

The API is reachable only inside our cloud network (VPC), so your client host must be inside it. The hostname has no public DNS record, so each client host maps it to the API host's private address. Ask the oracle owner for the hostname and the address.

Always connect by the hostname, not by the address, because TLS checks that the hostname matches the certificate.

Authentication

The oracle owner sends you a token separately. Send the header Authorization: Bearer <token> on every /v1 request, including the WebSocket upgrade at /v1/ws. Browser WebSocket clients cannot set this header, so connect from a server-side client.

Never put the token in a URL, a subscribe frame or a log.

Prices

priceWad always has 18 decimals: the price is priceWad / 10^18. In JSON it is a decimal string, not a number, so parse it as a 128-bit integer, never as a float.

Example: "62417250000000000000000" = 62417.25.

Limits

  • Each signed report is valid for 3 s.
  • An update becomes due when its price moves 5 basis points or more, when its status changes, or when 1000000 µs (the heartbeat) pass without an update. Each of these makes an update due, and the relayer aims to land a quiet feed's update within one heartbeat. It flags an update as late when it was observed more than one heartbeat after the last landed update was observed. The max wait is only a start-up ceiling on the heartbeat.
  • Requests: 100 HTTP requests per second in total, one budget shared by all clients. More than that returns 429.
  • Connections: 64 open connections in total, HTTP and WebSocket together. Up to 32 subscriptions per WebSocket connection, and at most 100 frames per second from each connection.

Use the WebSocket for live prices. If you poll HTTPS, poll no more than once per second per service. On 429, back off with jitter and don't retry in a tight loop. These limits are shared, so use one connection per service, not one per thread.

Verify a report

The API never checks its own signatures, so check every report yourself before you act on a price. Pin the signer, the chain id and the verifier from this page, never from an API response. The signer is 0xf78c522598a39d78e594a4815b2f4821d1cab79f, which is activeSigner() on the OracleAdmin below.

Hashing rules

  • Domain: TickrOracle, version 1, chain id 84257, verifying contract 0x78ba85a4bcbb8ead7ab7da0c17bbad840a99129f (the OracleVerifier). The domain type is EIP712Domain(string name,string version,uint256 chainId,address verifyingContract), and domainSeparator = keccak256(abi.encode(keccak256(domainType), keccak256("TickrOracle"), keccak256("1"), chainId, verifyingContract)).
  • The header type is SnapshotHeader(uint16 protocolVersion,uint32 configVersion,bytes32 configHash,uint64 writerEpoch,uint64 sequence,uint64 generatedAtUs,uint64 expiresAtUs,uint8 feedCount,bytes32 feedsRoot). The struct hash is keccak256(abi.encode(keccak256(headerType), the nine header fields)), and the digest is keccak256(0x1901 ‖ domainSeparator ‖ structHash).
  • The leaf type is FeedLeaf(bytes32 feedId,uint128 priceWad,uint64 observedAtUs,uint8 sourceMask,uint8 receiveOnlyMask,uint8 status,uint16 dispersionBps,uint32 reasonFlags). The leaf hash is keccak256(keccak256(abi.encode(keccak256(leafType), the eight leaf fields))). The second keccak256 stops a leaf from passing as an inner node.
  • Encode each field as one 32-byte ABI word, in the order of its type string. In the JSON, 64-bit and wider integers are decimal strings, and status is a name: VALID is 0, UNSAFE is 1 and HALTED is 2.
  • The tree has 32 slots. The real leaves, sorted by feedId as unsigned 32-byte numbers, fill slots 0 to feedCount − 1. Padding fills the other slots: slot i holds keccak256(keccak256(abi.encode(keccak256(paddingType), configHash, i))), where the padding type is TickrPadding(bytes32 configHash,uint8 slot) and i is the slot number. You need the padding only to rebuild the whole tree.
  • Every proof has exactly five sibling hashes. Start from the leaf hash and take each sibling in order. Join the two 32-byte values with the smaller one first, compared as unsigned numbers, and hash them: keccak256(min(a, b) ‖ max(a, b)). After five steps the result must equal header.feedsRoot. This is OpenZeppelin's MerkleProof rule.

Steps

  1. Read the OracleAdmin. Refuse to act while isHalted() or isRevoked() is true, or while activeSigner() is zero or differs from the pinned signer. Then check that protocolVersion is 1, and that writerEpoch, configHash and configVersion match activeEpoch(), configHash() and configVersion().
  2. Recompute the digest from header under the domain above and compare it with digest.
  3. Recover the signer with ecrecover(digest, v, r, s) and compare it with the pinned signer. digest is the final EIP-712 hash, so add no \x19Ethereum Signed Message prefix. signature is 65 bytes in the order r, s, v; v is 27 or 28, and s must be low. A recovered signer means nothing without step 2, because only the digest binds it to this header.
  4. Hash each leaf and fold it with its proof as above. The result must equal header.feedsRoot.
  5. Check every leaf the way the verifier's _validLeaf does, because the verifier refuses a batch that holds one bad leaf. isFeed(feedId) must be true, and status must be VALID, UNSAFE or HALTED. sourceMask may use only bits 0 to 3 and must be a subset of allowedSourceMask(feedId). receiveOnlyMask must be a subset of sourceMask. reasonFlags may use only bits 0 to 10, and when bit 5 (dispersion saturated) is set, dispersionBps must be 65535. A leaf that is not VALID must have priceWad and observedAtUs both zero. A VALID leaf must have a non-zero priceWad and at least two bits set in sourceMask, and its observedAtUs must be within 500 ms of generatedAtUs. Then use a feed's price only when its status is VALID, as getUsablePrice does. An UNSAFE or HALTED leaf makes only its own feed unusable, so the other feeds in the report stay usable. Read allowedSourceMask from the OracleAdmin, because the copy in /v1/feeds is unsigned advice.
  6. Reject the header unless expiresAtUs equals generatedAtUs + 3_000_000. For each feed you use, act only while generatedAtUs / 1e6 ≤ block.timestamp (with the left side rounded down) and block.timestamp is below the deadline ceil(min(expiresAtUs, observedAtUs + 3_000_000) / 1e6). Off chain, use the current Unix time in seconds as block.timestamp. labels and onchainRejectAtSec are unsigned advice, so never use them in place of this check.

Each adapter reads the OracleVerifier above and returns 8 decimals. Call latestRoundData(). It returns a price only while the OracleVerifier says that price is usable; otherwise it reverts with ExpiredReport, UnusableFeed or NoDataPresent. It also reverts with PriceBelowOneE8 or PriceExceedsUint64 when the converted price rounds to zero or exceeds uint64, and with RoundIdOverflow when the epoch or sequence is too large for the round ID. The adapter serves the current round only, the round ID that latestRoundData() returns: getRoundData for any other round reverts with NoDataPresent. latestUsableUntil() returns the current round and the second at which its price stops being usable.

The 2026-11-02 redeploy

After cutover, report links /v1/reports/1/<n> and AggregatorV3 round IDs repeat with different reports and prices, so drop every cached link and round ID from before cutover. Also drop every saved WebSocket resume watermark from before cutover, and subscribe without resume. A saved watermark points into the old contracts' history, so the server may refuse it, start over from a snapshot, or resume from the wrong place.
